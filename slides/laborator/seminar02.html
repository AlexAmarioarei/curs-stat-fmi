Planul seminarului și laboratorului

Statisticile cu care vom lucra tot semestrul — suma și media unui eșantion, minimul și maximul, rapoarte de tip „semnal/zgomot” — sunt funcții ale unui vector aleator, iar comportarea lor pentru eșantioane mari este descrisă de LNM și de TLC. Exersăm instrumentele din partea a doua a Cursul 1.

Obiective și teme.

  • F.g.m.: calcul, momente, recunoașterea unei repartiții, f.g.m. a unei sume de variabile independente.

  • Transformări de vectori aleatori: convoluție, metoda funcției de repartiție, schimbarea de variabilă cu o variabilă auxiliară; independența noilor variabile.
  • LNM, TLC, aproximări și lema lui Slutsky: inegalitatea lui Cebîșev, aplicații continue, verificarea ipotezelor, calcule aproximative cu și fără corecție de continuitate.
  • În R: simularea vectorilor aleatori, estimarea probabilităților, covarianțelor și corelațiilor, verificarea unei densități (integrate, ecdf, histogramă), ilustrarea LNM și a TLC.

Breviar: funcția generatoare de momente

Notații: \(S_n=X_1+\dots+X_n\), \(\Xbar=S_n/n\); \(\Phi\) este funcția de repartiție a repartiției \(\Norm(0,1)\), iar \(z_p=\Phi^{-1}(p)\) cuantila ei de ordin \(p\): \(z_{0.95}\approx1.645\), \(z_{0.975}\approx1.96\) (în R, qnorm(p)).

Rezultate din curs folosite azi
  • F.g.m. (Definiția 30 din Cursul 1): \(M_X(t)=\E[e^{tX}]\); \(X\) admite f.g.m. dacă \(M_X<\infty\) pe un interval \((-h,h)\), \(h>0\). Atunci \(\E[X^k]=M_X^{(k)}(0)\) și \(M_X(t)=\sum_{k\ge0}\E[X^k]\,t^k/k!\) pentru \(|t|<h\) (Teorema 32 din Cursul 1), iar f.g.m. determină repartiția (Teorema 33 din Cursul 1).
  • \(M_{a+bX}(t)=e^{at}M_X(bt)\) (Lema 31 din Cursul 1); pentru \(X_1,\dots,X_n\) independente, \(M_{X_1+\dots+X_n}=\prod_iM_{X_i}\), iar pentru i.i.d., \(M_{S_n}=M^n\) (Propoziția 46 din Cursul 1).
  • F.g.m. uzuale (Exemplele 21 din Cursul 1 și 22 din Cursul 1), cu \(q=1-p\) și \(\Exp(\lambda)=\GammaD(1,\lambda)\):

\[ \begin{array}{lllll} \Geom(p): & \dfrac{pe^t}{1-qe^t},\ \ t<-\ln q; &\quad& \Pois(\lambda): & e^{\lambda(e^t-1)},\ \ t\in\R;\\[3mm] \GammaD(\alpha,\lambda): & \Big(\dfrac{\lambda}{\lambda-t}\Big)^{\alpha},\ \ t<\lambda; && \Norm(\mu,\sigma^2): & e^{\mu t+\sigma^2t^2/2},\ \ t\in\R . \end{array} \]

Întrebare rapidă: care dintre aceste repartiții admit f.g.m. pe toată dreapta reală? (Poisson și normala.) Pentru geometrică și Gamma domeniul este o semidreaptă care conține 0. Cele trei utilizări ale f.g.m. — momente, unicitate, sume — apar în primele două exerciții.

Breviar: vectori aleatori și covarianță

Rezultate din curs folosite azi (continuare)
  • Vectori aleatori. Marginalele: \(f_X(x)=\int_{\R}f_{(X,Y)}(x,y)\dd y\), respectiv \(p_X(x)=\sum_yp_{(X,Y)}(x,y)\) (Propoziția 36 din Cursul 1). \(X\) și \(Y\) sunt independente dacă \(F_{(X,Y)}(x,y)=F_X(x)F_Y(y)\) pentru orice \((x,y)\) (Definiția 37 din Cursul 1); echivalent, dacă masa sau densitatea comună este produsul marginalelor; dacă densitatea comună este un produs \(a(u)\,b(v)\) pe tot spațiul, atunci \(U\) și \(V\) sunt independente, cu densitățile proporționale cu \(a\) și \(b\) (Propoziția 38 din Cursul 1).
  • Funcții de blocuri disjuncte de v.a. independente sunt independente (Propoziția 39 din Cursul 1), iar pentru \(X\), \(Y\) independente, \(\E[g(X)h(Y)]=\E[g(X)]\,\E[h(Y)]\) (Propoziția 40 din Cursul 1).
  • Covarianța (Definiția 41 din Cursul 1, Propoziția 42 din Cursul 1): \(\Cov(X,Y)=\E[XY]-\E X\,\E Y\) este biliniară; \(\Var(\sum_iX_i)=\sum_i\Var X_i+2\sum_{i<j}\Cov(X_i,X_j)\); independența implică necorelarea (nu și invers); \(|\rho(X,Y)|\le1\).
  • Pentru v.a. i.i.d. cu media \(\mu\) și varianța \(\sigma^2\): \(\E[\Xbar]=\mu\), \(\Var(\Xbar)=\sigma^2/n\) (Corolarul 43 din Cursul 1).

De subliniat: factorizarea densității comune trebuie să aibă loc pe tot spațiul, nu doar pe suport; un suport care nu este un produs de intervale exclude independența. Vom vedea azi două perechi necorelate, dar dependente.

Breviar: transformări de vectori aleatori

Rezultate din curs folosite azi (continuare)
  • Transformări de vectori aleatori (Secțiunea 7.5 din Cursul 1). Metoda funcției de repartiție: \(F_{g(X,Y)}(z)=\iint_{\{g(x,y)\le z\}}f_{(X,Y)}(x,y)\dd x\dd y\); dacă \(F\) este continuă și de clasă \(C^1\) pe porțiuni, densitatea este \(F'\) (Lema 16 din Cursul 1).
  • Pentru \(X\), \(Y\) independente, cu densități (Propozițiile 50 din Cursul 1 și 51 din Cursul 1): \[ \begin{aligned} f_{X+Y}(z)&=\int_{\R}f_X(x)\,f_Y(z-x)\dd x, &\qquad f_{X/Y}(z)&=\int_{\R}|y|\,f_X(zy)\,f_Y(y)\dd y,\\ F_{\max(X,Y)}&=F_XF_Y, & 1-F_{\min(X,Y)}&=(1-F_X)(1-F_Y). \end{aligned} \]
  • Schimbarea de variabilă (Teorema 52 din Cursul 1): dacă \(\PP(X\in S)=1\) și \(h:S\to\R^d\) este injectivă, de clasă \(C^1\), cu \(J_h\ne0\) pe mulțimea deschisă \(S\), atunci \(Y=h(X)\) are densitatea \(f_Y(y)=f_X\big(h^{-1}(y)\big)\,|J_{h^{-1}}(y)|\,\Ind_{h(S)}(y)\).
  • Pentru o singură funcție \(U=g_1(X,Y)\) adăugăm o variabilă auxiliară \(V=g_2(X,Y)\), calculăm \(f_{(U,V)}\) și integrăm în \(v\).

În toate exercițiile de transformare formula se scrie imediat; greșelile apar la domeniu: mulțimea pe care integrandul este nenul, imaginea transformării, forma mulțimii pe care funcția este cel mult z.

Breviar: convergențe și teoreme limită

Rezultate din curs folosite azi (continuare)
  • Convergențe (Definiția 55 din Cursul 1, Teorema 56 din Cursul 1): \(\asto\ \Rightarrow\ \pto\ \Rightarrow\ \dto\), iar \(X_n\dto c\) (constantă) \(\Rightarrow X_n\pto c\). Aplicații continue (Teorema 57 din Cursul 1): dacă \(g\) este continuă în afara unei mulțimi \(D_g\) cu \(\PP(X\in D_g)=0\), atunci \(g(X_n)\to g(X)\) în același sens în care \(X_n\to X\). Slutsky (Teorema 58 din Cursul 1): dacă \(X_n\dto X\) și \(Y_n\pto c\) (constantă), atunci \(X_n+Y_n\dto X+c\) și \(Y_nX_n\dto cX\).
  • Cebîșev, LNM, TLC. \(\PP(|X-\E X|\ge\varepsilon)\le\Var(X)/\varepsilon^2\) (Propoziția 26 din Cursul 1(b)). Pentru \(X_i\) i.i.d. cu media \(\mu\) și varianța \(\sigma^2\): \(\PP(|\Xbar-\mu|\ge\varepsilon)\le\sigma^2/(n\varepsilon^2)\), deci \(\Xbar\pto\mu\) (Teorema 60 din Cursul 1); dacă doar \(\E|X_1|<\infty\), \(\Xbar\asto\mu\) (Teorema 61 din Cursul 1). Dacă \(\sigma^2\in(0,\infty)\), \(\sqrt n(\Xbar-\mu)/\sigma\dto\Norm(0,1)\) (Teorema 64 din Cursul 1), deci \(S_n\approx\Norm(n\mu,n\sigma^2)\) și \(\Xbar\approx\Norm(\mu,\sigma^2/n)\). Pentru \(S_n\sim\Bin(n,p)\) (Corolarul 65 din Cursul 1) și \(k\) întreg, corecția de continuitate: \(\PP(S_n\le k)\approx\Phi\big((k+0.5-np)/\sqrt{np(1-p)}\big)\).
  • Curtiss (Teorema 63 din Cursul 1): dacă \(M_{X_n}(t)\to M_X(t)<\infty\) pentru orice \(t\in(-h,h)\), atunci \(X_n\dto X\); limita se obține de obicei din \((1+a_n/n)^n\to e^a\) pentru \(a_n\to a\) (Lema 62 din Cursul 1).

În lema lui Slutsky limita lui Y_n trebuie să fie o constantă. Întrebare: ce ipoteză cere TLC și nu cere legea tare? (varianță finită și nenulă)

Instrumente R folosite azi
  • Parametrizări-capcană. geom și nbinom numără eșecurile: pentru \(X\sim\Geom(p)\), \(\PP(X=k)\) este dgeom(k - 1, p), iar rgeom(n, p) + 1 generează valori ale lui \(X\); pentru \(\NBin(r,p)\), dnbinom(k - r, r, p). exp și gamma folosesc rata, norm folosește abaterea standard.
  • replicate(B, expr) — repetă de B ori o simulare; matrix(v, nrow = B) cu rowMeans, colSums — B eșantioane pe linii (sau pe coloane) și mediile (sumele) lor.

  • integrate(f, a, b)$value — integrala numerică a lui f; uniroot(h, c(a, b))$root — o soluție a ecuației \(h(x)=0\) în \([a,b]\).
  • ecdf(x)(q) — proporția valorilor \(\le\) q; pmin, pmax — minimul și maximul pe componente; ifelse(cond, a, b) — funcții pe ramuri; cumsum(x) / (1:n) — mediile cumulate; hist(x, freq = FALSE), apoi curve(f(x), add = TRUE) — histograma normalizată și densitatea.

F.g.m.: calcul, momente, recunoașterea repartițiilor

F.g.m. a repartițiilor uniformă și binomială negativă

Exercițiul 1 (F.g.m. a repartițiilor uniformă și binomială negativă)

  1. Fie \(X\sim\Unif(a,b)\), \(a<b\). Pornind de la f.g.m. a lui \(X\), deduceți toate momentele \(\E[X^k]\), apoi \(\E[X]\) și \(\Var(X)\).

  2. Repartiția binomială negativă \(\NBin(r,p)\), \(r\in\N^*\), \(p\in(0,1)\), este repartiția numărului \(X\) de încercări independente necesare pentru a obține \(r\) succese, fiecare încercare fiind un succes cu probabilitatea \(p\): \(\PP(X=k)=\binom{k-1}{r-1}p^r(1-p)^{k-r}\), \(k\ge r\). Calculați \(M_X\), arătați că \(X\) are aceeași repartiție ca suma a \(r\) variabile independente \(\Geom(p)\) și deduceți \(\E[X]\) și \(\Var(X)\).

  3. Recunoașteți repartițiile variabilelor \(V\) și \(W\) cu f.g.m. \(M_V(t)=\big(\frac{0.2\,e^{t}}{1-0.8\,e^{t}}\big)^3\) (\(t<-\ln0.8\)) și \(M_W(t)=\frac{e^{t}}{(1-2t)^3}\) (\(t<1/2\)) și calculați \(\E[V]\), \(\Var(V)\), \(\PP(V=5)\), \(\E[W]\), \(\Var(W)\) și \(\PP(W\le5)\).

  4. În R: verificați valorile de la (c), calculând momentele lui \(V\) prin derivarea numerică a lui \(M_V\) și simulând \(V\) ca sumă de variabile geometrice.

Cele trei utilizări ale f.g.m.: calculul efectiv (o serie sau o integrală), obținerea momentelor și recunoașterea unei repartiții. Cu f.g.m. vom obține, în cursurile următoare, repartițiile exacte ale statisticilor.

F.g.m. uniformă și binomială negativă — rezolvare (a)

Soluție

Seminar (a) Din Exemplul 21 din Cursul 1, \(M_X(t)=\frac{e^{tb}-e^{ta}}{t(b-a)}\) pentru \(t\ne0\) și \(M_X(0)=1\); \(M_X(t)<\infty\) pentru orice \(t\in\R\). Nu derivăm câtul: în \(t=0\) el are forma \(0/0\). Folosim seria exponențialei, \(e^{tb}-e^{ta}=\sum_{j\ge1}\frac{t^j(b^j-a^j)}{j!}\); împărțind la \(t(b-a)\) și notând \(k=j-1\), \[ M_X(t)=\sum_{k\ge0}\frac{b^{k+1}-a^{k+1}}{(k+1)!\,(b-a)}\,t^k,\qquad t\in\R . \] Din Teorema 32 din Cursul 1, \(M_X(t)=\sum_{k\ge0}\E[X^k]\,t^k/k!\). Coeficienții unei serii de puteri fiind unici, identificăm coeficienții lui \(t^k\): \[ \E[X^k]=\frac{k!\,\big(b^{k+1}-a^{k+1}\big)}{(k+1)!\,(b-a)}=\frac{b^{k+1}-a^{k+1}}{(k+1)(b-a)},\qquad k\ge0 . \] Pentru \(k=1\): \(\E[X]=\frac{b^2-a^2}{2(b-a)}=\frac{a+b}{2}\); pentru \(k=2\): \(\E[X^2]=\frac{b^3-a^3}{3(b-a)}=\frac{a^2+ab+b^2}{3}\). Deci \(\Var(X)=\frac{a^2+ab+b^2}{3}-\frac{(a+b)^2}{4}=\frac{(b-a)^2}{12}\).

Întrebare: de ce nu derivăm direct câtul? (în t = 0 are forma 0/0) Dezvoltarea în serie dă toate momentele dintr-o dată, prin identificarea coeficienților.

F.g.m. uniformă și binomială negativă — rezolvare (b)

Soluție (continuare)

Seminar (b) Seria binomială negativă. Derivând de \(r-1\) ori, termen cu termen, seria geometrică \(\sum_{m\ge0}x^m=(1-x)^{-1}\) și împărțind la \((r-1)!\), obținem \(\sum_{j\ge0}\binom{j+r-1}{r-1}x^j=\frac{1}{(1-x)^r}\) pentru \(|x|<1\), \(r\in\N^*\).

F.g.m. Fie \(q=1-p\). Cu \(j=k-r\) și seria de mai sus pentru \(x=qe^t\), \[ M_X(t)=\sum_{k\ge r}e^{tk}\binom{k-1}{r-1}p^rq^{k-r}=(pe^t)^r\sum_{j\ge0}\binom{j+r-1}{r-1}(qe^t)^j=\Big(\frac{pe^t}{1-qe^t}\Big)^r,\qquad t<-\ln q \] (pentru \(t\ge-\ln q\), \(M_X(t)=\infty\)). Reprezentarea ca sumă. Fie \(G_1,\dots,G_r\) i.i.d. \(\Geom(p)\). Din Propoziția 46 din Cursul 1(c), \(M_{G_1+\dots+G_r}=M_{G_1}^r=M_X\) pe \((-h,h)\), cu \(h=-\ln q>0\); din Teorema 33 din Cursul 1, \(X\eqd G_1+\dots+G_r\). Cu \(\E[G_1]=\frac1p\) și \(\Var(G_1)=\frac{q}{p^2}\) (Exemplul 23 din Cursul 1), din liniaritatea mediei și din Propoziția 42 din Cursul 1(d), \[ \E[X]=r\,\E[G_1]=\frac rp,\qquad \Var(X)=r\Var(G_1)=\frac{r(1-p)}{p^2} . \]

Interpretarea este naturală: numărul de încercări până la al r-lea succes este suma numerelor de încercări dintre succese consecutive. Luând t = 0 în formulă obținem și că probabilitățile din enunț au suma 1.

F.g.m. uniformă și binomială negativă — rezolvare (c)

Soluție (continuare)

Seminar (c) \(M_V\) este f.g.m. de la (b) cu \(r=3\) și \(p=0.2\), pe intervalul \(t<-\ln0.8\), care conține \(0\); din Teorema 33 din Cursul 1, \(V\sim\NBin(3,0.2)\). Deci \[ \E[V]=\frac{3}{0.2}=15,\qquad \Var(V)=\frac{3\cdot0.8}{0.04}=60,\qquad \PP(V=5)=\binom42(0.2)^3(0.8)^2=0.03072 . \] Pentru \(W\): \(\frac{1}{(1-2t)^3}=\big(\frac{1/2}{1/2-t}\big)^3\) este f.g.m. a repartiției \(\GammaD(3,\frac12)\). Dacă \(G\sim\GammaD(3,\frac12)\), Lema 31 din Cursul 1 dă \(M_{1+G}(t)=e^tM_G(t)=M_W(t)\) pentru \(t<\frac12\), deci \(W\eqd1+G\): o variabilă Gamma translatată cu \(1\). Rezultă \(\E[W]=1+\frac{3}{1/2}=7\), \(\Var(W)=\Var(G)=\frac{3}{(1/2)^2}=12\) și, cu densitatea \(\frac{x^2e^{-x/2}}{16}\) a lui \(G\) și substituția \(u=x/2\), \[ \PP(W\le5)=\PP(G\le4)=\int_0^4\frac{x^2e^{-x/2}}{16}\dd x=\frac12\int_0^2u^2e^{-u}\dd u=1-5e^{-2}\approx0.323 . \]

Recunoașterea se sprijină pe teorema de unicitate: f.g.m. trebuie să coincidă pe un interval care conține 0. Factorul exponențial din f.g.m. a lui W înseamnă o translație. Primitiva folosită în ultima integrală este minus exponențiala înmulțită cu u pătrat plus 2u plus 2.

F.g.m. uniformă și binomială negativă — în R

Soluție

Laborator (d) dnbinom(x, size, prob) dă probabilitatea a x eșecuri înaintea celui de-al size-lea succes. Derivatele \(M_V'(0)=\E[V]\) și \(M_V''(0)=\E[V^2]\) le aproximăm prin diferențe finite centrate.

dnbinom(5 - 3, size = 3, prob = 0.2)       # P(V = 5): 2 eșecuri
MV <- function(t) (0.2 * exp(t) / (1 - 0.8 * exp(t)))^3
h <- 1e-4                                   # pasul diferențelor finite
m1 <- (MV(h) - MV(-h)) / (2 * h)            # aproximează M'(0) = E[V]
m2 <- (MV(h) - 2 * MV(0) + MV(-h)) / h^2    # aproximează M''(0) = E[V^2]
c(E_V = m1, Var_V = m2 - m1^2)              # teoretic: 15 și 60
#> [1] 0.03072
#>   E_V Var_V 
#>    15    60

Regăsim \(\PP(V=5)=0.03072\), iar derivatele numerice reproduc \(\E[V]=15\) și \(\Var(V)=60\).

Atenție la parametrizare: dnbinom și rgeom numără eșecurile, nu încercările, deci probabilitatea ca V să fie 5 corespunde la 2 eșecuri. Derivatele f.g.m. în 0 sunt aproximate prin diferențe finite centrate, cu pasul h.

F.g.m. a unei sume. Repartiția Laplace

Cele trei proprietăți ale f.g.m. (momente, unicitate, sume), folosite pentru a obține direct o convergență în repartiție — schema demonstrației TLC din Cursul 1.

Exercițiul 2 (F.g.m. a unei sume. Repartiția Laplace)

Fie \(X_1,X_2,\dots\) i.i.d. cu densitatea \(f(x)=\frac12e^{-|x-\theta|}\), \(x\in\R\) (repartiția Laplace sau dublu exponențială), unde \(\theta\in\R\).

  1. Arătați că \(M_{X_1}(t)=\dfrac{e^{\theta t}}{1-t^2}\) pentru \(|t|<1\) și deduceți \(\E[X_1]\) și \(\Var(X_1)\).

  2. Fie \(E_1,E_2\) i.i.d. \(\Exp(1)\). Arătați că \(\theta+E_1-E_2\) are aceeași repartiție ca \(X_1\).

  3. Fie \(U_n=(S_n-n\theta)/\sqrt{2n}\). Calculați \(M_{U_n}\) și arătați direct, fără a folosi TLC, că \(U_n\dto\Norm(0,1)\).

  4. Pentru \(\theta=0\) și \(n=50\), aproximați \(\PP(|\Xbar|\le0.3)\) și verificați prin simulare, generând observațiile cu reprezentarea de la (b).

Exercițiul urmează schema demonstrației TLC din Cursul 1: f.g.m. a sumei calculată exact, apoi trecerea la limită și teorema lui Curtiss. Punctul (b) dă și o metodă de simulare a repartiției Laplace, folosită la (d).

Repartiția Laplace — rezolvare (a), (b)

Soluție

Seminar (a) \(Y=X_1-\theta\) are densitatea \(\frac12e^{-|y|}\). Împărțim integrala după semnul lui \(y\) (prima integrală este finită dacă și numai dacă \(1+t>0\), a doua dacă și numai dacă \(1-t>0\)): \[ M_Y(t)=\frac12\int_{-\infty}^0e^{(1+t)y}\dd y+\frac12\int_0^\infty e^{-(1-t)y}\dd y=\frac12\Big(\frac1{1+t}+\frac1{1-t}\Big)=\frac{1}{1-t^2},\qquad |t|<1 . \] Din Lema 31 din Cursul 1, \(M_{X_1}(t)=e^{\theta t}M_Y(t)=\frac{e^{\theta t}}{1-t^2}\), \(|t|<1\). Exercițiul 3 (Un vector cu densitatea exponențială pe un sector)

Vectorul aleator \((X,Y)\) are densitatea \(f(x,y)=c\,e^{-y}\) pentru \(0<x<y\) și \(f(x,y)=0\) în rest.

  1. Determinați constanta \(c\) și densitățile marginale; recunoașteți repartițiile lui \(X\) și \(Y\). Sunt \(X\) și \(Y\) independente?

  2. Calculați \(\Cov(X,Y)\), \(\rho(X,Y)\) și \(\PP(Y>2X)\).

  3. Fie \(D=Y-X\). Arătați că \(X\) și \(D\) sunt independente, cu repartiția \(\Exp(1)\), și regăsiți rezultatele de la (a) și (b).

  4. În R: simulați \(10^5\) realizări ale vectorului \((X,Y)\) cu reprezentarea dată de (c), estimați mediile, matricea de covarianță și corelațiile și reprezentați un nor de puncte. Ce observați despre raportul \(U=X/Y\)?

Cereți studenților să deseneze suportul înainte de orice calcul: un sector al primului cadran, deasupra primei bisectoare. Forma suportului decide deja independența.

Vectorul pe un sector — rezolvare (a)

Soluție

Seminar (a) Constanta. Integrăm întâi după \(x\in(0,y)\) (teorema lui Fubini, integrand nenegativ), apoi după \(y\): \[ 1=\int_0^\infty\Big(\int_0^yc\,e^{-y}\dd x\Big)\dd y=c\int_0^\infty y\,e^{-y}\dd y=c\,\Gamma(2)=c,\qquad\text{deci } c=1 . \] Marginalele. Din Propoziția 36 din Cursul 1, pentru \(x>0\) integrăm după \(y\) pe secțiunea verticală \((x,\infty)\), iar pentru \(y>0\) integrăm după \(x\) pe secțiunea orizontală \((0,y)\): \[ f_X(x)=\int_x^\infty e^{-y}\dd y=e^{-x},\quad x>0;\qquad f_Y(y)=\int_0^ye^{-y}\dd x=y\,e^{-y},\quad y>0 . \] Deci \(X\sim\Exp(1)\) și \(Y\sim\GammaD(2,1)\); în particular \(\E[X]=\Var(X)=1\) și \(\E[Y]=\Var(Y)=2\).

Independența. \(X\) și \(Y\) nu sunt independente: suportul nu este un produs de intervale. Pe evenimente: \(\PP(X>1,\ Y\le1)=0\) (pe suport \(X<Y\)), pe când \(\PP(X>1)\,\PP(Y\le1)=e^{-1}(1-2e^{-1})\approx0.097>0\): relația de produs din Definiția 37 din Cursul 1 nu are loc.

Marginalele: secțiunea verticală pentru X, cea orizontală pentru Y. Un suport care nu este un produs de intervale exclude independența; aici o arătăm și pe un eveniment concret.

Vectorul pe un sector — rezolvare (b)

Soluție (continuare)

Seminar (b) Din formula de transfer pentru vectori (Secțiunea 7.3 din Cursul 1) și Fubini, \[ \E[XY]=\int_0^\infty\Big(\int_0^yx\dd x\Big)y\,e^{-y}\dd y=\int_0^\infty\frac{y^3}{2}\,e^{-y}\dd y=\frac{\Gamma(4)}{2}=3 . \] Din Propoziția 42 din Cursul 1(a), \(\Cov(X,Y)=\E[XY]-\E[X]\,\E[Y]=3-1\cdot2=1\), iar \(\rho(X,Y)=\frac{1}{\sqrt{1\cdot2}}=\frac{1}{\sqrt2}\approx0.707\). Corelația pozitivă era previzibilă: valori mari ale lui \(X\) forțează valori mari ale lui \(Y\).

Pentru \(\{Y>2X\}\), la \(x>0\) fixat, \(y\) parcurge \((2x,\infty)\): \[ \PP(Y>2X)=\int_0^\infty\Big(\int_{2x}^\infty e^{-y}\dd y\Big)\dd x=\int_0^\infty e^{-2x}\dd x=\frac12 . \]

Vectorul pe un sector — rezolvare (c)

Soluție (continuare)

Seminar (c) Pentru \(a,b>0\), \(\{X\le a,\ D\le b\}=\{X\le a,\ X<Y\le X+b\}\), deci \[ F_{(X,D)}(a,b)=\int_0^a\Big(\int_x^{x+b}e^{-y}\dd y\Big)\dd x=\int_0^a\big(e^{-x}-e^{-x-b}\big)\dd x=\big(1-e^{-a}\big)\big(1-e^{-b}\big), \] iar \(F_{(X,D)}(a,b)=0\) dacă \(a\le0\) sau \(b\le0\). Făcând \(a\to\infty\), \(F_D(b)=1-e^{-b}\), iar \(F_X(a)=1-e^{-a}\) din (a). Deci \(F_{(X,D)}=F_X\,F_D\) pe \(\R^2\): din Definiția 37 din Cursul 1, \(X\) și \(D\) sunt independente, ambele \(\Exp(1)\).

Consecințe. \(Y=X+D\), deci \(Y\sim\GammaD(2,1)\) (Exemplul 31 din Cursul 1), ca la (a). Din biliniaritatea covarianței și \(\Cov(X,D)=0\) (Propoziția 42 din Cursul 1(b), (d)), \[ \Cov(X,Y)=\Cov(X,X+D)=\Var(X)+\Cov(X,D)=1,\qquad \Var(Y)=\Var(X)+\Var(D)=2, \] fără nicio integrală dublă. Subțierea unei variabile Poisson

Un fenomen surprinzător, specific repartiției Poisson; exersăm criteriul de factorizare în cazul discret.

Exercițiul 4 (Subțierea unei variabile Poisson)

O găină depune un număr aleator \(N\sim\Pois(\lambda)\) de ouă (\(\lambda>0\)); fiecare ou eclozează cu probabilitatea \(p\in(0,1)\), independent de celelalte ouă și de \(N\). Fie \(X\) numărul de ouă din care ies pui și \(Y=N-X\) numărul celorlalte ouă; notăm \(q=1-p\).

  1. Arătați că \(\PP(X=k,Y=m)=\PP(N=k+m)\binom{k+m}{k}p^kq^m\) pentru \(k,m\ge0\) și deduceți că \(X\sim\Pois(\lambda p)\), \(Y\sim\Pois(\lambda q)\) și că \(X\) și \(Y\) sunt independente.

  2. Calculați \(\Cov(N,X)\) și \(\rho(N,X)\).

  3. Ce se schimbă dacă numărul de ouă este fix, \(N=n\)?

  4. În R: simulați modelul pentru \(\lambda=4\) și \(p=0.3\) și verificați (a) și (b).

Întrebați studenții, înainte de rezolvare: numărul de pui dă informație despre numărul de ouă neeclozate? Majoritatea vor răspunde „da”. Exercițiul exersează criteriul de factorizare în cazul discret.

Subțierea Poisson — rezolvare (a)

Soluție

Seminar (a) Repartiția comună. Cum \(Y=N-X\), \(\{X=k,Y=m\}=\{N=k+m,\ X=k\}\), iar din formula înmulțirii (Propoziția 6 din Cursul 1), \(\PP(X=k,Y=m)=\PP(N=k+m)\,\PP(X=k\mid N=k+m)\). Știind că \(N=k+m\), cele \(k+m\) ouă eclozează independent, fiecare cu probabilitatea \(p\), deci numărul celor eclozate are repartiția \(\Bin(k+m,p)\) și \(\PP(X=k\mid N=k+m)=\binom{k+m}kp^kq^m\). Folosind \(\lambda^{k+m}=\lambda^k\lambda^m\) și \(e^{-\lambda}=e^{-\lambda p}e^{-\lambda q}\), \[ \PP(X=k,Y=m)=e^{-\lambda}\frac{\lambda^{k+m}}{(k+m)!}\cdot\frac{(k+m)!}{k!\,m!}\,p^kq^m =\underbrace{e^{-\lambda p}\frac{(\lambda p)^k}{k!}}_{g(k)}\cdot\underbrace{e^{-\lambda q}\frac{(\lambda q)^m}{m!}}_{h(m)} . \] Marginalele și independența. \(g\) și \(h\) sunt funcțiile de masă ale repartițiilor \(\Pois(\lambda p)\) și \(\Pois(\lambda q)\). Din Propoziția 36 din Cursul 1, \(\PP(X=k)=\sum_{m\ge0}g(k)h(m)=g(k)\) și \(\PP(Y=m)=h(m)\): \(X\sim\Pois(\lambda p)\) și \(Y\sim\Pois(\lambda q)\). Mai mult, \(p_{(X,Y)}(k,m)=p_X(k)\,p_Y(m)\) pentru orice \(k,m\), deci, din Propoziția 38 din Cursul 1(a), \(X\) și \(Y\) sunt independente.

Rezultatul este contraintuitiv: numărul de pui nu dă nicio informație despre numărul de ouă neeclozate. Pentru o repartiție Poisson, a afla că s-au născut mulți pui crește estimarea numărului total de ouă exact cât trebuie pentru a compensa.

Subțierea Poisson — rezolvare (b), (c)

Soluție (continuare)

Seminar (b) Din \(N=X+Y\), biliniaritatea covarianței și \(\Cov(X,Y)=0\) (Propoziția 42 din Cursul 1(b), (d)), \[ \Cov(N,X)=\Cov(X+Y,X)=\Var(X)+\Cov(Y,X)=\lambda p,\qquad \rho(N,X)=\frac{\lambda p}{\sqrt{\lambda\cdot\lambda p}}=\sqrt p , \] unde am folosit \(\Var(N)=\lambda\) și \(\Var(X)=\lambda p\). Corelația nu depinde de \(\lambda\): cu cât \(p\) este mai mare, cu atât numărul de pui „urmărește” mai fidel numărul de ouă.

(c) Dacă \(N=n\) este fix, atunci \(X\sim\Bin(n,p)\) și \(Y=n-X\), deci \(\Cov(X,Y)=\Cov(X,n-X)=-\Var(X)=-npq<0\); \(Y\) fiind o funcție afină descrescătoare de \(X\), \(\rho(X,Y)=-1\) (Propoziția 42 din Cursul 1(e)). Independența de la (a) este deci o proprietate a modelului cu \(N\) Poisson, nu a mecanismului de subțiere.

Varianța repartiției Poisson este egală cu parametrul. Punctul (c) arată că independența nu vine din mecanismul de subțiere, ci din repartiția Poisson a numărului total.

Semnal plus zgomot — rezolvare (a)

Soluție

Seminar Densitățile sunt \(f_X(x)=\frac1a\Ind_{(0,a)}(x)\) și \(f_Y(y)=\lambda e^{-\lambda y}\Ind_{(0,\infty)}(y)\).

Pentru \(z\le0\), \(f_Z(z)=0\); pentru \(z>0\), \[ f_Z(z)=\frac1a\int_0^{\min(a,z)}\lambda e^{-\lambda(z-x)}\dd x=\frac{e^{-\lambda z}}{a}\big(e^{\lambda\min(a,z)}-1\big) =\begin{cases}\dfrac{1-e^{-\lambda z}}{a},&0<z\le a,\\[8pt]\dfrac{(e^{\lambda a}-1)\,e^{-\lambda z}}{a},&z>a .\end{cases} \] Verificare: \(\int_0^a\frac{1-e^{-\lambda z}}{a}\dd z=1-\frac{1-e^{-\lambda a}}{\lambda a}\) și \(\int_a^\infty\frac{(e^{\lambda a}-1)e^{-\lambda z}}{a}\dd z=\frac{1-e^{-\lambda a}}{\lambda a}\), iar suma este \(1\).

Exercițiul 6 (Fracțiunea din timpul total: metoda variabilei auxiliare)

Un echipament pornește cu o componentă principală, înlocuită, la defectare, de o componentă de rezervă. Timpii lor de funcționare, \(X\) și \(Y\), sunt strict pozitivi, iar vectorul \((X,Y)\) are densitatea \(f\). Ne interesează fracțiunea \(Z=\dfrac{X}{X+Y}\) din timpul total de funcționare \(V=X+Y\) asigurată de componenta principală.

  1. Folosind variabila auxiliară \(V\), arătați că vectorul \((Z,V)\) are densitatea \(f_{(Z,V)}(z,v)=v\,f\big(zv,(1-z)v\big)\) pentru \(0<z<1\), \(v>0\) (și \(0\) în rest) și scrieți densitatea lui \(Z\).
  2. Fie \(X\sim\Exp(\lambda)\) și \(Y\sim\Exp(\mu)\) independente. Determinați densitatea și funcția de repartiție ale lui \(Z\). Pentru ce valori ale parametrilor sunt \(Z\) și \(V\) independente? Ce rezultă pentru raportul \(U\) din Exercițiul 3?
  3. Fie \(X\) și \(Y\) independente, \(\Unif(0,1)\). Determinați densitatea lui \(Z\). Sunt \(Z\) și \(V\) independente? Dar necorelate?
  4. În R: verificați prin simulare rezultatele de la (b), pentru \((\lambda,\mu)=(1,3)\) și \((\lambda,\mu)=(2,2)\), și pe cele de la (c); reprezentați norii de puncte \((z_i,v_i)\).

Formula schimbării de variabilă dă repartiția comună a noilor variabile și permite să decidem dacă ele sunt independente. Când ne interesează o singură funcție a vectorului, o completăm cu o variabilă auxiliară. Exercițiul arată și cât de mult depinde răspunsul de repartiția vectorului inițial.

Fracțiunea din timpul total — rezolvare (a)

Soluție

Seminar (a) Mulțimea \(S=(0,\infty)^2\) este deschisă și \(\PP\big((X,Y)\in S\big)=1\). Funcția \(h(x,y)=\big(\frac{x}{x+y},\,x+y\big)\) este de clasă \(C^1\) pe \(S\), cu \(J_h(x,y)=\frac{y}{(x+y)^2}+\frac{x}{(x+y)^2}=\frac{1}{x+y}\ne0\).

Pentru \((x,y)\in S\) avem \(z=\frac{x}{x+y}\in(0,1)\) și \(v=x+y>0\). Reciproc, pentru \(z\in(0,1)\) și \(v>0\), sistemul \(\frac{x}{x+y}=z\), \(x+y=v\) are soluția unică \(x=zv\), \(y=(1-z)v\), cu ambele componente strict pozitive. Deci \(h\) este injectivă, imaginea ei este \(T=h(S)=(0,1)\times(0,\infty)\), iar \[ h^{-1}(z,v)=\big(zv,\,(1-z)v\big),\qquad J_{h^{-1}}(z,v)=\det\begin{pmatrix}v&z\\-v&1-z\end{pmatrix}=v(1-z)+vz=v . \] Din Teorema 52 din Cursul 1, apoi integrând variabila auxiliară (Propoziția 36 din Cursul 1), \[ f_{(Z,V)}(z,v)=v\,f\big(zv,\,(1-z)v\big)\,\Ind_T(z,v),\qquad f_Z(z)=\int_0^\infty v\,f\big(zv,\,(1-z)v\big)\dd v,\quad 0<z<1 . \]

Verificați cu studenții, pe rând, ipotezele teoremei: mulțimea deschisă de probabilitate 1, clasa C1, iacobianul nenul, injectivitatea și imaginea. Iacobianul inversei este inversul iacobianului lui h, adică x + y = v.

Fracțiunea din timpul total — rezolvare (b)

Soluție (continuare)

Seminar (b) Acum \(f(x,y)=\lambda e^{-\lambda x}\,\mu e^{-\mu y}\) pe \(S\); cu \(c(z)=\lambda z+\mu(1-z)>0\), \(f_{(Z,V)}(z,v)=\lambda\mu\,v\,e^{-c(z)\,v}\) pe \(T\), deci \[ f_Z(z)=\frac{\lambda\mu}{\big(\lambda z+\mu(1-z)\big)^2},\quad 0<z<1;\qquad F_Z(z)=\frac{\lambda z}{\lambda z+\mu(1-z)},\quad 0\le z\le1 \] (\(F_Z\): din \(\{Z\le z\}=\big\{\frac XY\le\frac{z}{1-z}\big\}\) și \(\PP\big(\frac XY\le t\big)=\frac{\lambda t}{\lambda t+\mu}\), Exemplul 37 din Cursul 1).

Independența. Dacă \(\lambda=\mu\), atunci \(f_{(Z,V)}(z,v)=\Ind_{(0,1)}(z)\cdot\lambda^2v\,e^{-\lambda v}\,\Ind_{(0,\infty)}(v)\) pe \(\R^2\): un produs, pe tot planul, între densitatea \(\Unif(0,1)\) și densitatea \(\GammaD(2,\lambda)\). Din Propoziția 38 din Cursul 1(c), \(Z\sim\Unif(0,1)\) și \(V\sim\GammaD(2,\lambda)\) sunt independente.

Dacă \(\lambda\ne\mu\) și \(Z\), \(V\) ar fi independente, \(f_Z(z)f_V(v)\) ar coincide cu \(f_{(Z,V)}\) pe \(T\), deci \(\frac{f_Z(z)}{f_Z(z')}=e^{-(\lambda-\mu)(z-z')v}\) pentru \(z\ne z'\) — imposibil: membrul stâng nu depinde de \(v\). Așadar \(Z\) și \(V\) sunt independente dacă și numai dacă \(\lambda=\mu\).

Raportul din Exercițiul 3. Acolo \(X\) și \(D=Y-X\) sunt i.i.d. \(\Exp(1)\), \(Y=X+D\): cazul \(\lambda=\mu=1\) dă \(U=\frac{X}{X+D}=\frac XY\sim\Unif(0,1)\), independentă de \(Y\).

Seminar (c) Acum \(f=\Ind_{(0,1)^2}\), deci \(f\big(zv,(1-z)v\big)=1\) dacă \(zv<1\) și \((1-z)v<1\) și \(0\) altfel. Distanța de la un colț — rezolvare (a): cazul \(1<r<\sqrt2\)

Soluție (continuare)

Seminar Discul iese din pătrat, dar nu îl acoperă. Fie \(\alpha=\arccos\frac1r\in\big(0,\frac\pi4\big)\), deci \(r\cos\alpha=1\) și \(\tan\alpha=\sqrt{r^2-1}\): unghiul polar al punctului în care cercul de rază \(r\) taie latura \(x=1\). Împărțim pătratul după unghiul polar \(\theta\in(0,\frac\pi2)\).

  • Pentru \(\theta\le\alpha\), semidreapta de unghi \(\theta\) iese din pătrat prin latura \(x=1\), la distanța \(\frac{1}{\cos\theta}\le r\): toate punctele pătratului cu unghiul polar cel mult \(\alpha\) aparțin lui \(A_r\) — triunghiul cu vârfurile \((0,0)\), \((1,0)\) și \((1,\tan\alpha)\), de arie \(\frac12\tan\alpha=\frac12\sqrt{r^2-1}\).
  • Pentru \(\theta\ge\frac\pi2-\alpha\), prin simetria față de prima bisectoare, un triunghi de aceeași arie.
  • Pentru \(\alpha<\theta<\frac\pi2-\alpha\), semidreapta iese din pătrat la o distanță mai mare decât \(r\): un sector de cerc de rază \(r\) și unghi \(\frac\pi2-2\alpha\), de arie \(\frac{r^2}{2}\big(\frac\pi2-2\alpha\big)\).

Adunând cele trei arii, \(F_D(r)=\sqrt{r^2-1}+r^2\big(\frac\pi4-\arccos\frac1r\big)\) pentru \(1<r<\sqrt2\), iar \(F_D(r)=1\) pentru \(r\ge\sqrt2\) și \(F_D(r)=0\) pentru \(r\le0\). Volumul unui sondaj — rezolvare (a), (b)

Soluție

Seminar (a) \(S_n\) este suma a \(n\) v.a. i.i.d. \(\Bern(p)\), deci, din Corolarul 43 din Cursul 1, \(\E[\hat p_n]=p\) și \(\Var(\hat p_n)=\frac{p(1-p)}{n}\le\frac1{4n}\). Marginea este cel mult \(0.05\) dacă \(n\ge\frac{1}{4\cdot0.0009\cdot0.05}\approx5555.6\), deci \(n=5556\) este suficient, pentru orice \(p\) (și fără nicio aproximare).

(b) Din Corolarul 65 din Cursul 1, \(U_n=\sqrt n(\hat p_n-p)/\sqrt{p(1-p)}\approx\Norm(0,1)\). Împărțind inegalitatea \(|\hat p_n-p|\le0.03\) la \(\sqrt{p(1-p)/n}\) și folosind relația (2) din Exercițiul 2, apoi \(\sqrt{p(1-p)}\le\frac12\) și monotonia lui \(\Phi\), \[ \PP(|\hat p_n-p|\le0.03)=\PP\Big(|U_n|\le\frac{0.03\sqrt n}{\sqrt{p(1-p)}}\Big)\approx2\Phi\Big(\frac{0.03\sqrt n}{\sqrt{p(1-p)}}\Big)-1\ge2\Phi\big(0.06\sqrt n\big)-1 . \] Ultima expresie este cel puțin \(0.95\) dacă \(0.06\sqrt n\ge z_{0.975}=1.96\), adică \(n\ge(1.96/0.06)^2\approx1067.1\); deci \(n=1068\). Volumul unui sondaj — rezolvare (c)

Soluție (continuare)

Seminar (c) Pasul 1 (TLC). Variabilele \(\Bern(p)\) au \(\mu=p\) și \(\sigma^2=p(1-p)\in(0,\infty)\), deci \(U_n=\frac{\sqrt n(\hat p_n-p)}{\sqrt{p(1-p)}}\dto\Norm(0,1)\).

Pasul 2 (LNM și aplicații continue). Din Teorema 60 din Cursul 1, \(\hat p_n\pto p\). Prelungim funcția \(x\mapsto\sqrt{\frac{p(1-p)}{x(1-x)}}\), continuă pe \((0,1)\), la o funcție \(g:\R\to\R\), punând \(g(x)=1\) pentru \(x\notin(0,1)\). Punctele de discontinuitate ale lui \(g\) se află în \(\{0,1\}\), mulțime care nu conține limita \(p\in(0,1)\); din Teorema 57 din Cursul 1(b), \(V_n:=g(\hat p_n)\pto g(p)=1\).

Pasul 3 (Slutsky). Avem \(U_n\dto\Norm(0,1)\) și \(V_n\pto1\) (constantă), deci, din Teorema 58 din Cursul 1(b), \(U_nV_n\dto\Norm(0,1)\). Pe evenimentul \(E_n=\{0<\hat p_n<1\}\), \[ U_nV_n=\frac{\sqrt n(\hat p_n-p)}{\sqrt{p(1-p)}}\cdot\sqrt{\frac{p(1-p)}{\hat p_n(1-\hat p_n)}}=\frac{\sqrt n(\hat p_n-p)}{\sqrt{\hat p_n(1-\hat p_n)}}=Z_n . \]

Trei pași: TLC pentru numărător, LNM și aplicații continue pentru raportul abaterilor standard, Slutsky pentru produs. De subliniat: în lema lui Slutsky limita celui de-al doilea șir trebuie să fie o constantă; aici ea este 1.

Volumul unui sondaj — rezolvare (c): intervalul

Soluție (continuare)

Seminar Pe \(E_n^c=\{S_n=0\}\cup\{S_n=n\}\) numitorul lui \(Z_n\) se anulează; acolo dăm lui \(Z_n\) o valoare oarecare. Pentru orice \(\varepsilon>0\), \(\PP(|Z_n-U_nV_n|>\varepsilon)\le\PP(E_n^c)=(1-p)^n+p^n\to0\), deci \(Z_n-U_nV_n\pto0\) și, din Teorema 58 din Cursul 1(a), \(Z_n=U_nV_n+(Z_n-U_nV_n)\dto\Norm(0,1)\).

Intervalul. Din relația (2), \(\PP(|Z_n|\le1.96)\to2\Phi(1.96)-1=0.95\). Rezolvăm inegalitatea în \(p\): pe \(E_n\), \[ |Z_n|\le1.96\iff\hat p_n-1.96\sqrt{\frac{\hat p_n(1-\hat p_n)}{n}}\le p\le\hat p_n+1.96\sqrt{\frac{\hat p_n(1-\hat p_n)}{n}} . \] Intervalul aleator din dreapta, ale cărui capete depind doar de date, conține \(p\) cu probabilitatea aproximativ \(0.95\): este intervalul de încredere Wald (Cursul 12).

Pentru datele din enunț, \(\hat p=587/1068\approx0.5496\) și \(1.96\sqrt{0.5496\cdot0.4504/1068}\approx0.0298\), deci intervalul este \([0.5198,\ 0.5795]\): cu încredere de aproximativ \(95\%\), propunerea este susținută de o majoritate. Rolul lemei lui Slutsky este esențial: fără ea nu am putea înlocui \(p\) necunoscut cu \(\hat p_n\) în numitor.

Capetele intervalului depind doar de date: aceasta este diferența față de calculul de la (b), unde abaterea standard conținea parametrul necunoscut. Intervalele de încredere asimptotice sunt studiate sistematic într-un curs ulterior.

traiectorii <- function(rgen, N, M) {
  X <- matrix(rgen(N * M), nrow = N)   # coloana j: un șir X_1, ..., X_N
  apply(X, 2, cumsum) / (1:N)          # coloana j: n -> media primelor n
}

medii_std <- function(rgen, mu, sigma, n, B = 2e4) {
  x <- matrix(rgen(n * B), nrow = B)      # B eșantioane de volum n
  sqrt(n) * (rowMeans(x) - mu) / sigma    # B medii standardizate
}

  • Vectori aleatori: un suport care nu este un produs de intervale exclude independența; o reprezentare prin variabile independente simplifică și calculul covarianțelor, și simularea.
  • Transformări: partea delicată este domeniul. În R: integrala densității este \(1\) (integrate), frecvențele urmează funcția de repartiție (ecdf), histograma urmează densitatea.
  • O corelație apropiată de \(0\) nu dovedește independența.
  • Cebîșev: instrument de demonstrație, nu de calcul. TLC: aproximarea normală a binomialei (cu corecție de continuitate) cere \(np\) și \(n(1-p)\) mari, cea Poisson \(p\) mic.
  • Slutsky: înlocuirea unui parametru necunoscut cu un estimator (intervalul Wald); „cu probabilitatea \(0.95\)” este o afirmație asimptotică. „Regula” \(n\ge30\) nu este universală: normalitatea se instalează cu atât mai lent, cu cât populația este mai asimetrică.

Recapitulare a concluziilor exercițiilor de azi, în ordinea temelor. Cereți studenților câte un exemplu din ședință pentru fiecare punct: de exemplu, perechile necorelate, dar dependente, sau volumul sondajului calculat cu Cebîșev și cu TLC.
